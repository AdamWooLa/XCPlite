本模块是平铺式的示例目录集合，每个子目录都是一个自包含的可构建工程，通过各自的 CMakeLists.txt / Makefile / platformio.ini / build.sh 独立编译，不共享源码。
- 基础 API 示例：hello_xcp / hello_xcp_cpp / c_demo / cpp_demo / struct_demo / multi_thread_demo / point_cloud_demo，统一遵循 `XcpInit → XcpEthServerInit → A2lInit → 创建 CalSeg/DaqEvent → 循环触发` 的初始化与测量流程，并通过 CANape/ 项目文件夹中的 `.a2l`、`.cna`、`CANape.ini` 完成工具链对接。
- 无运行时 A2L 示例：no_a2l_demo / no_a2l_demo_cpp，依赖外部 `xcpclient` 从 ELF/DWARF 离线生成 A2L，目标端不调用任何 `a2l.h`。
- 嵌入式 FreeRTOS 示例：freertos_demo 下分 emu（POSIX 模拟器）、esp32（PlatformIO）、stm32（CubeMX+CMake）三个平台，共享顶层 `xcp_demo.c/.h` 应用代码，通过 `_FREE_RTOS` 和 `XCPLIB_CFG_OVERRIDE="xcplib_rtos_cfg.h"` 切换平台路径。
- 高级集成示例：silkit_demo 通过 CMake `find_package(SilKit)` + `find_package(xcplite)` 链接已安装的 libxcplite（要求 shm 配置），拆分为 Publisher/Subscriber/XcpServer 三个可执行；fetchcontent_example / external_example 演示以 FetchContent 或系统安装方式消费 xcplite；cmp_demo 在应用层实现 `eth_hal_*` 六个 HAL 函数将 XCP 隧道封装进 ASAM CMP；udp_raw_demo 使用 raw Ethernet HAL 绕过 TCP/IP 栈；bpf_demo 使用 eBPF 追踪进程与 syscall；ptp4l_demo 展示 PTP 时间戳源。
- 所有示例均通过根级 README.md 中列出的 `cmake -B build -DXCPLITE_CONFIGURATION=...` 不同配置（default/no_a2l/ptp/shm/rtos/raw）选择对应库变体进行构建。
