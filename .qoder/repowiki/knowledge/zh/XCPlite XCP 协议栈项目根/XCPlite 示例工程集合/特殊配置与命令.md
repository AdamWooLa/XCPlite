根 README 指定按功能选择 XCPlite 配置：`cmake -B build -DXCPLITE_CONFIGURATION=default|no_a2l|ptp|shm|rtos|raw`；freertos_esp32_demo 需 PlatformIO 环境；freeRTOS 示例需用 `xcpclient --offline ... --elf <elf> --a2l <a2l>` 从 DWARF 离线生成 A2L；silkit_demo 要求已安装 `XCPLITE_CONFIGURATION=shm` 的 libxcplite；udp_raw_demo/cmp_demo 在 Linux 上需要 `CAP_NET_RAW`。
