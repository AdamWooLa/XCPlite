- 每个示例工程采用统一的初始化序列：`XcpSetLogLevel` → `XcpInit` → `XcpEthServerInit` → `A2lInit` → 创建校准段/事件 → 主循环中 `XcpLockCalSeg`/`XcpUnlockCalSeg` 访问参数并 `DaqTriggerEvent` 采集。
- 校准参数通过 `XcpCreateCalSeg`（或 C++ `xcp::CalSeg<T>` / `CalSegDeclRef`）声明为带工作页/参考页的段，并以 `A2lSetSegmentAddrMode` 绑定到 A2L 描述。
- 测量变量按地址域显式设置寻址模式：全局变量用 `A2lSetAbsoluteAddrMode`，局部/栈变量用 `A2lSetStackAddrMode`，模块基址相对变量用 `A2lSetRelativeAddrMode`。
- 示例工程自带 `CANape/` 子目录，内含 `CANape.ini`、`CanapeCmd.ini`、`XCP_104.aml`、`.cna` 与自动生成的 `_autodetect.a2l`，用于一键加载到 CANape。
- C 与 C++ 双版本示例（如 hello_xcp / hello_xcp_cpp、no_a2l_demo / no_a2l_demo_cpp）保持相同功能边界，仅通过 RAII 包装与 variadic 宏差异体现语言风格。
- 复杂数据对象统一通过 `A2lTypedefBegin/End` + `A2lTypedef*Component` 定义 typedef，再以 `A2lCreateTypedefInstance` 注册为测量或校准对象。
