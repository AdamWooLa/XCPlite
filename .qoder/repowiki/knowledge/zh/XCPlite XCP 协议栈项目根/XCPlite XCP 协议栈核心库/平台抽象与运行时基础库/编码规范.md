- 通过 `#if defined(_WIN) / _LINUX / _MACOS / _QNX / _FREE_RTOS` 在头文件中用宏块对同一 API 提供不同平台实现（如 MUTEX、create_thread、sleepUs 等）。
- 公共函数与结构体统一用 `extern "C"` 包裹，使 C++ 消费者可直接链接。
- 队列实现遵循生产者-单消费者语义：producer 侧线程安全，consumer 侧通过 `queuePeek`/`queuePop` 获取句柄后由调用者负责顺序释放（`queueRelease`）。
- 可配置特性集中通过 `xcplib_cfg.h`/`xcptl_cfg.h` 中的 `OPTION_*` 宏控制，并在编译期用 `static_assert`/`#error` 校验对齐与尺寸约束。
- 调试输出通过 `dbg_print.h` 的 `DBG_PRINTF_ERROR/WARNING/3/4/5/6` 宏按级别裁剪，关闭 `OPTION_ENABLE_DBG_PRINTS` 时全部展开为空语句。
- 数据结构采用环形缓冲 + 索引维护模式（如 `tMedianFilter` 的 `samples[]`/`order[]`、队列的 `rp`/`queue_len` 指针），避免动态分配。
