本模块按三层组织：
- 底层 socket 抽象（sockets.c/h）：通过编译期宏 OPTION_ENABLE_TCP / OPTION_ENABLE_UDP / OPTION_ENABLE_UDP_RAW 三选一，分别接入 POSIX/Windows/lwIP 原生 socket 或纯软件实现的原始以太网堆栈；Linux + OPTION_SOCKET_HW_TIMESTAMPS 时 SOCKET_HANDLE 包装 struct socket* 以支持硬件时间戳。
- 原始以太网 HAL 层（socket_raw.c + socket_raw_hal.h + socket_raw_hal_linux.c）：在 OPTION_ENABLE_UDP_RAW 下完全绕过 OS 网络栈，手工拼装 Ethernet/IPv4/UDP 帧并实现 ARP 应答与 ICMP Echo Reply，HAL 接口 eth_hal_* 由 socket_raw_hal_linux.c（AF_PACKET）提供，且支持通过 OPTION_UDP_RAW_HAL_EXTERNAL 由应用替换后端。
- 上层 XCP 传输层（xcpethtl.c/h, xcpethserver.c/h）：封装 socket 收发为 XCP CTO/DTO/CRM/EVENT 消息，维护主从地址、多播组、TCP/UDP 双模式；xcpethserver 创建接收/发送两个线程并通过 queue 解耦，支持 SHM_MODE 共享队列与可选的多播线程。
依赖方向严格自上而下：xcpethserver → xcpethtl → sockets/socket_raw → HAL；socket_raw 不反向依赖上层，仅暴露 socket API 子集供调用者使用。
