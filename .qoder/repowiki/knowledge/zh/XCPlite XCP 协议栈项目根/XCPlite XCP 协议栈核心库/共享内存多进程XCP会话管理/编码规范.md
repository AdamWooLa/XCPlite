- 所有跨进程共享字段统一声明为 atomic_uint_least32_t 并通过 atomic_load/store/fetch_add 访问，避免非原子读写。
- 共享内存结构体使用 static_assert 校验尺寸对齐：tApp 固定 512 字节，tShmHeader 控制区严格 64 字节（一行缓存行）。
- 对外 API 以 XcpShm* 前缀命名，并在函数入口通过 isInitialized_ / isActivated_ 断言 gXcpData 与 magic/version 有效后再操作。
- 应用槽位访问一律先检查 app_id < SHM_MAX_APP_COUNT，越界返回空值或零值而非崩溃。
- 调试输出统一通过 DBG_PRINT* / DBG_PRINTF* 宏并以 ANSI 颜色转义包裹，区分 INFO/WARNING/ERROR 级别。
- SHM 模式代码整体由 #ifdef OPTION_SHM_MODE 包裹，非 SHM 模式下仅保留 XcpIsInShmMode() 返回 false 的 stub。
