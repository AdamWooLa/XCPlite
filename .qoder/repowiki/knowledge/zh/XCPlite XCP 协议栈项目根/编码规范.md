- 所有子模块通过 CMake 选项 `XCPLITE_BUILD_*` 显式启用，默认关闭以避免无关产物污染构建目录。
- 跨平台差异通过 `XCPLITE_CONFIGURATION` 选择的配置头与 `#ifdef WIN32/UNIX/APPLE` 条件编译实现，而非 fork 源码树。
- 对外暴露的公共 API 集中在 `inc/` 下的 `.h/.hpp` 双头文件，C/C++ 消费者均通过 `xcplite::xcplite` 命名空间链接。
- 子工程（examples/tests/tools）均以 `PRIVATE` 方式链接 `xcplite`，避免将库的 PUBLIC 定义泄漏给下游。
