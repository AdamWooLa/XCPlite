测试目录按功能划分为若干独立可执行子工程，每个子工程对应一个被测特性：
- `a2l_test`、`cal_test`、`daq_test`、`clock_test`、`xcp_test`、`queue_test`、`type_detection_test`、`daq_config_test`、`socket_raw_test`：各含 `src/main.c(.cpp)`，通过 `xcplib.h` / `a2l.h` / `platform.h` 等内部头调用 XCPlite API，启动 XCP 服务器并触发 DAQ/校准/A2L 生成流程。
- `eth_transport_test`：直接 `#include "xcpethtl.c"` 并在其之上重定义 `socketRecv/socketRecvFrom` 宏以注入错误注入（EINTR/EINVAL/MSGSIZE），用真实 loopback socket 对 TCP/UDP 帧边界、超时、恢复进行回归测试，并通过 `fork` + `SIGPIPE` 隔离子进程。
- `fixtures/`：存放各示例生成的 A2L 基准文件，供 `test.sh` 在运行时 diff 比对。
- 顶层 shell 脚本构成统一编排层：`test.sh` 负责发现 `build/` 下的示例二进制、后台启动、调用 `xcpclient` 连接、转换 BIN→HEX 并与 fixtures 比较；`test_bintool.sh` 通过 ssh/rsync 在远端目标（Raspberry Pi）上同步源码、构建、启动 XCP 服务，再用 `xcpclient --upload-bin` 和 `bintool` 做 HEX 双向转换与完整性校验；`test_socket_raw.sh`、`test_bpf_demo_pi.sh` 分别覆盖原始套接字与 BPF 演示路径。
依赖方向单向：测试程序 → libxcplite 公共 API → 平台抽象（`platform.h`/`sockets.h`）；脚本仅依赖外部工具 `bintool`、`a2ltool`、`xcpclient`，不反向依赖代码。
